# IVSH — painel interativo

Painel interativo do Índice de Vulnerabilidade Socioambiental de Sistemas Hídricos (IVSH), proposto para a Gerência Metropolitana da COGERH.

- `index.html`: o painel, com o percurso da evidência ao índice, as quatro dimensões, os 18 indicadores, o simulador e, na abertura, o jogo *A Régua das Águas*. É um arquivo único e funciona sem internet.
- `Artigo_IVSH.pdf`: o artigo que propõe o índice.

Os valores do painel e do jogo são fictícios ou ilustrativos. O índice não foi aplicado a açudes reais.

Página publicada: https://appcomai.github.io/IVSH_Framework/
